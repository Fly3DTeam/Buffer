# Fly Buffer 缓冲器固件

这是 Fly Buffer/LLL Buffer 缓冲器的 PlatformIO 固件工程，用于在 3D 打印耗材路径中检测缓冲位置、控制 BMG 送料机构、输出断料/堵料状态，并与 TMC2225 步进驱动通信。

英文说明见 [README_EN.md](README_EN.md)，版本更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 主要功能

- 通过三路光感判断缓冲器位置：
  - `HALL3`：前进位，触发后向前送料。
  - `HALL2`：停止位，触发后立即停止电机。
  - `HALL1`：后退位，触发后回退耗材。
- 支持本机耗材开关和可选 MDM 断堵料模块。
- 支持断料输出、堵料输出、状态指示灯和启动指示灯。
- 使用 STEP/DIR 定时器脉冲控制电机，速度单位为 `mm/s`。
- 使用 BMG 齿轮送料参数计算步进脉冲。
- 使用 TMC2225 驱动，固件按 TMC2208 兼容寄存器类通信。
- 支持串口命令保存速度、加速度、电流、堵料检测参数和输出电平。
- 支持硬件看门狗，提高异常情况下的恢复能力。

## 工作逻辑

- 自动控制时停止位优先级最高。检测到停止位后，固件会立即关闭 STEP 脉冲，再在主循环中完成电流、静音模式和使能状态恢复；单键长按手动控制的优先级高于停止位。
- 正常速度由 `speed` 命令设置，单位为 `mm/s`，默认 `30mm/s`。
- 加速度由 `accel` 命令设置，单位为 `mm/s^2`，默认 `500mm/s^2`。
- 运动方向由缓冲器光感、按键或外部前进/后退信号决定。
- 固件分为 TPU 和非 TPU 两种耗材模式，模式保存在 EEPROM 中，掉电重启后保持不变；新设备及旧版固件首次升级默认进入非 TPU 模式。
- TPU 模式：运行电流固定为 `400mA RMS` 并禁止高速补偿；电机停止后保持驱动使能，`IHOLD=0` 使用最小非零保持电流（满量程的 `1/32`，默认配置下约 `30mA RMS`），静止 `30s` 后失能。固件显式设置 `PWMCONF.freewheel=0`，所以该档位保持正常电流调节，不会进入自由滑行或被动制动。
- 非 TPU 模式：允许运动超过 `100mm` 时进入高速补偿，目标速度提升到 `100mm/s`；电机一旦停止便立即失能，不保留静止电流。
- 高速补偿前会适当提高电流并切换高速模式；退出高速时按 `accel` 平滑恢复普通速度，减速完成后恢复原电流和静音模式。
- 无耗材时不会触发高速补偿。
- 统一使用 16 细分，降低 STEP 中断频率，提高 100mm/s 高速运行稳定性。

## 按键控制

- 单击任意按键：解除暂停/错误状态，恢复自动工作。
- 双击任意按键：暂停自动工作并停止电机。
- 长按后退键：手动回退；长按前进键：手动前进。单键长按具有最高优先级，按住期间忽略三路缓冲光感（包括停止位 HALL2），松开后立即恢复传感器保护；外部前进/后退信号不享受此优先级。
- 同时按下两个按键：立即切换 TPU/非 TPU 模式并保存到 EEPROM，全部松开后才允许再次切换。
- 切换 TPU/非 TPU 模式不会触发额外状态灯提示，状态灯继续显示当前工作或故障状态。

## 断料逻辑

- 上电时如果没有耗材，立即按无料处理。
- 只有从“有耗材”变为“无耗材”后，才进入 10 秒延时。
- 这 10 秒内电机继续按缓冲器逻辑工作，只延迟断料输出和指示灯通知。
- 如果 10 秒内重新上料，延时取消并恢复正常状态。
- 如果 10 秒内重新上下料，会重新开始计时。

## 超时错误恢复

- 如果持续前进超过 `timeout` 设置值，会进入超时错误并停机。
- 超时错误发生后，单击按键、执行手动按键控制、双键切换耗材模式，或耗材状态发生变化（重新上料/下料），都会清除超时错误并恢复工作。
- 暂停状态也会被上述恢复操作清除；双击任意单个按键仍用于主动进入暂停。
- 其它手动触发的错误不会被误当作超时错误清除。

## 状态灯

`ERR_LED / PA15` 的全部指示方式如下：

| 灯效 | 时序 | 是否循环 | 表示状态 |
| --- | --- | --- | --- |
| 三连快闪后停顿 | 每次亮/灭各 `80ms`，三闪后熄灭 `700ms` | 是 | TMC 通信、配置或驱动状态连续异常 |
| 连续快速闪烁 | 每 `50ms` 翻转一次 | 是 | 检测到堵料 |
| 连续超快闪烁 | 每 `25ms` 翻转一次 | 是 | 前进运行超过 `timeout`，进入超时错误 |
| 常亮 | 持续点亮 | 是 | 双击按键后进入暂停状态 |
| 双闪 | 亮 `100ms`、灭 `100ms`、亮 `100ms`，再熄灭 `600ms` | 是 | 工作正常，已连接 MDM 模块 |
| 慢闪 | 亮 `500ms`、灭 `500ms` | 是 | 工作正常，未连接 MDM 模块 |

多个状态同时存在时，显示优先级为：TMC 异常 → 堵料 → 前进超时 → 暂停 → MDM 已连接 → 正常未连接 MDM。

`START_LED / PA8` 为耗材灯：TPU 模式有耗材时闪烁，非 TPU 模式有耗材时常亮，确认断料后熄灭。

### TPU/非 TPU 模式识别

- TPU 模式：有耗材时耗材灯闪烁。
- 非 TPU 模式：有耗材时耗材灯常亮。

## 默认参数

下列可配置参数均保存在 EEPROM 中，修改后掉电不丢失：

| 参数 | 默认值 | 单位/说明 | 修改方式 |
| --- | ---: | --- | --- |
| 耗材模式 | 非 TPU | 非 TPU 启用快速补偿并在停止后立即失能 | 同时按下两个按键 |
| 前进超时时间 `timeout` | `60000` | `ms`，即连续前进 `60s` 后进入超时错误 | `timeout <value>` |
| 普通运动速度 `speed` | `30` | `mm/s` | `speed <value>` |
| 加速度/减速度 `accel` | `500` | `mm/s²` | `accel <value>` |
| 非 TPU 运行电流 `I_CURRENT` | `500` | `mA RMS`，命令允许范围 `100–3000mA` | `I <value>` |
| 主控挤出脉冲换算 `steps` | `916` | `pulse/mm`，允许范围 `1–51200` | `steps <value>` |
| MDM 编码器单脉冲长度 `encoder_length` | `1.73` | `mm/pulse` | `encoder <value>` |
| 堵料允许误差倍率 `allow_error_scale` | `2` | 默认允许误差为 `1.73 × 2 = 3.46mm` | `scale <value>` |
| 断料输出有效电平 | `0` | `DUANLIAO` 低电平有效 | `out <0/1>` |

主要固定参数如下：

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 断料确认延时 | `10s` | 曾经检测到耗材后，连续无料达到该时间才确认断料 |
| 快速补偿触发距离 | `100mm` | 仅非 TPU 模式可触发 |
| 快速补偿目标速度 | `100mm/s` | 普通速度低于该值时提升到此速度 |
| 快速补偿电流倍率 | `1.2` | 运行电流的 `120%`，代码上限 `3000mA` |
| TPU 运行电流 | `400mA RMS` | TPU 模式固定值，不受 `I` 命令影响 |
| TPU 静止保持电流 | `IHOLD=0` | 满量程的 `1/32`，默认配置下约 `30mA RMS` |
| TPU 停止失能延时 | `30s` | 期间保留静止保持电流 |
| 非 TPU 停止失能延时 | `0s` | 停止后立即失能 |
| 电机细分 | `16` | 普通与快速补偿统一使用 16 细分 |
| BMG 减速比 | `3:1` | 用于电机 STEP 脉冲换算 |
| BMG 驱动轮周长 | `22.93mm` | 用于电机 STEP 脉冲换算 |
| 看门狗超时 | 约 `4s` | 主循环卡死后通常约 `4–5s` 复位 |

## 串口命令

命令以换行结束。

| 命令 | 说明 |
| --- | --- |
| `info` | 查看当前主要参数 |
| `version` | 查看固件版本 |
| `speed` | 查看当前速度 |
| `speed <value>` | 设置速度，单位 `mm/s` |
| `accel` | 查看当前加速度 |
| `accel <value>` | 设置加速度，单位 `mm/s^2` |
| `I` | 查看 TMC 电流 |
| `I <value>` | 设置非 TPU 模式运行电流，范围 `100-3000mA` |
| `timeout <value>` | 设置前进超时时间，单位 `ms` |
| `rt` | 查看前进超时时间 |
| `steps <value>` | 设置主控脉冲换算参数 |
| `encoder <value>` | 设置 MDM 每脉冲对应耗材长度 |
| `scale <value>` | 设置堵料检测允许误差倍率 |
| `out <0/1>` | 设置断料输出有效电平 |
| `clear` | 清除堵料检测计数 |
| `flyboot` | 进入 bootloader |

## 构建

1. 安装 VS Code。
2. 安装 PlatformIO IDE 插件。
3. 打开本工程目录。
4. 执行 PlatformIO Build，或在终端运行：

```bash
pio run
```

当前工程环境为 `fly_f072cb`。
