# Fly Buffer 缓冲器固件

这是 Fly Buffer/LLL Buffer 缓冲器的 PlatformIO 固件工程，用于在 3D 打印耗材路径中检测缓冲位置、控制 BMG 送料机构、输出断料/堵料状态，并与 TMC2225 步进驱动通信。

英文说明见 [README_EN.md](README_EN.md)。

## 主要功能

- 通过三路光感判断缓冲器位置：
  - `HALL3`：前进位，触发后向前送料。
  - `HALL2`：停止位，触发后立即停止电机。
  - `HALL1`：后退位，触发后回退耗材。
- 支持本机耗材开关和可选 MDM 断堵料模块。
- 支持断料输出、堵料输出、状态指示灯和启动指示灯。
- 使用 STEP/DIR 定时器脉冲控制电机，速度单位为 `mm/s`。
- 使用 BMG 齿轮送料参数计算步进脉冲。
- 使用 TMC2225 驱动，固件按 TMC2208 兼容寄存器类通信。
- 支持串口命令保存速度、加速度、电流、堵料检测参数和输出电平。
- 支持硬件看门狗，提高异常情况下的恢复能力。

| 耗材灯 | `START_LED / PA8` | 有料状态/TPU 模式提示 |

## 工作逻辑

- 停止位优先级最高。检测到停止位后，固件会立即关闭 STEP 脉冲，再在主循环中完成电流、静音模式和使能状态恢复。
- 正常速度由 `speed` 命令设置，单位为 `mm/s`，默认 `30mm/s`。
- 加速度由 `accel` 命令设置，单位为 `mm/s^2`，默认 `500mm/s^2`。
- 运动方向由缓冲器光感、按键或外部前进/后退信号决定。
- 固件分为 TPU 和非 TPU 两种耗材模式，模式保存在 EEPROM 中，掉电重启后保持不变；新设备及旧版固件首次升级默认进入非 TPU 模式。
- TPU 模式：禁止高速补偿；电机停止后保持驱动使能，`IHOLD=1` 使用最小非零保持档（满量程的 `2/32`），静止 `30s` 后失能。
- 非 TPU 模式：允许运动超过 `100mm` 时进入高速补偿，目标速度提升到 `100mm/s`；电机一旦停止便立即失能，不保留静止电流。
- 高速补偿前会适当提高电流并切换高速模式；退出高速时按 `accel` 平滑恢复普通速度，减速完成后恢复原电流和静音模式。
- 无耗材时不会触发高速补偿。
- 统一使用 16 细分，降低 STEP 中断频率，提高 100mm/s 高速运行稳定性。

## 按键控制

- 单击任意按键：解除暂停/错误状态，恢复自动工作。
- 双击任意按键：暂停自动工作并停止电机。
- 长按后退键：手动回退；长按前进键：手动前进。
- 同时按下两个按键：立即切换 TPU/非 TPU 模式并保存到 EEPROM，全部松开后才允许再次切换。
- 切换到非 TPU 模式时状态灯明显闪烁五次（亮、灭各 `200ms`）；切换到 TPU 模式时状态灯长亮 `2s` 后熄灭 `500ms`。提示只执行一轮，随后恢复原有状态指示。

## 断料逻辑

- 上电时如果没有耗材，立即按无料处理。
- 只有从“有耗材”变为“无耗材”后，才进入 10 秒延时。
- 这 10 秒内电机继续按缓冲器逻辑工作，只延迟断料输出和指示灯通知。
- 如果 10 秒内重新上料，延时取消并恢复正常状态。
- 如果 10 秒内重新上下料，会重新开始计时。

## 超时错误恢复

- 如果持续前进超过 `timeout` 设置值，会进入超时错误并停机。
- 超时错误发生后，单击按键、执行手动按键控制、双键切换耗材模式，或耗材状态发生变化（重新上料/下料），都会清除超时错误并恢复工作。
- 暂停状态也会被上述恢复操作清除；双击任意单个按键仍用于主动进入暂停。
- 其它手动触发的错误不会被误当作超时错误清除。

## 状态灯

`ERR_LED / PA15` 的全部指示方式如下：

| 灯效 | 时序 | 是否循环 | 表示状态 |
| --- | --- | --- | --- |
| 五次明显闪烁 | 亮 `200ms`、灭 `200ms`，共五次 | 否 | 已切换到非 TPU 模式 |
| 长亮后熄灭 | 长亮 `2s`，再熄灭 `500ms` | 否 | 已切换到 TPU 模式 |
| 三连快闪后停顿 | 每次亮/灭各 `80ms`，三闪后熄灭 `700ms` | 是 | TMC 通信、配置或驱动状态连续异常 |
| 连续快速闪烁 | 每 `50ms` 翻转一次 | 是 | 检测到堵料 |
| 连续超快闪烁 | 每 `25ms` 翻转一次 | 是 | 前进运行超过 `timeout`，进入超时错误 |
| 常亮 | 持续点亮 | 是 | 双击按键后进入暂停状态 |
| 双闪 | 亮 `100ms`、灭 `100ms`、亮 `100ms`，再熄灭 `600ms` | 是 | 工作正常，已连接 MDM 模块 |
| 慢闪 | 亮 `500ms`、灭 `500ms` | 是 | 工作正常，未连接 MDM 模块 |

多个状态同时存在时，显示优先级为：耗材模式切换提示 → TMC 异常 → 堵料 → 前进超时 → 暂停 → MDM 已连接 → 正常未连接 MDM。一次性的模式提示结束后，会自动恢复当前状态对应的循环灯效。

`START_LED / PA8` 为耗材灯：TPU 模式有料时与 `ERR_LED` 反相交替闪烁（状态灯亮时耗材灯灭，状态灯灭时耗材灯亮）；非 TPU 模式有料时常亮；确认断料后熄灭。断料后的 `10s` 延时期间仍按有料状态显示。

## 串口命令

命令以换行结束。

| 命令 | 说明 |
| --- | --- |
| `info` | 查看当前主要参数 |
| `version` | 查看固件版本 |
| `speed` | 查看当前速度 |
| `speed <value>` | 设置速度，单位 `mm/s` |
| `accel` | 查看当前加速度 |
| `accel <value>` | 设置加速度，单位 `mm/s^2` |
| `I` | 查看 TMC 电流 |
| `I <value>` | 设置 TMC 电流，范围 `100-3000mA` |
| `timeout <value>` | 设置前进超时时间，单位 `ms` |
| `rt` | 查看前进超时时间 |
| `steps <value>` | 设置主控脉冲换算参数 |
| `encoder <value>` | 设置 MDM 每脉冲对应耗材长度 |
| `scale <value>` | 设置堵料检测允许误差倍率 |
| `out <0/1>` | 设置断料输出有效电平 |
| `clear` | 清除堵料检测计数 |
| `flyboot` | 进入 bootloader |

## 构建

1. 安装 VS Code。
2. 安装 PlatformIO IDE 插件。
3. 打开本工程目录。
4. 执行 PlatformIO Build，或在终端运行：

```bash
pio run
```

当前工程环境为 `fly_f072cb`。

## 版本变更

### 2.0.3

- 新增掉电保存的 TPU/非 TPU 耗材模式，双键同时按下切换。
- TPU 模式关闭高速补偿，使用最小非零静止电流并在停止 30 秒后失能。
- 非 TPU 模式启用高速补偿，停止后立即失能。
- TPU 模式有料时，耗材灯与状态灯反相交替闪烁；非 TPU 模式有料时常亮。

### 2.0.1

- 固件版本更新为 `2.0.1`。
- 电机控制改为 STEP/DIR 定时器脉冲输出。
- 速度单位改为 `mm/s`，新增 `accel` 加速度设置命令。
- BMG 齿轮参数用于步进脉冲换算。
- 统一使用 16 细分，降低 100mm/s 高速时的 STEP 中断压力。
- 超过 `100mm` 无状态变化时自动提速到 `100mm/s`。
- 提速时提高电流并切换高速模式，停止后恢复原电流和静音模式。
- TMC2225 改用 TMC2208 兼容类通信。
- 增加 TMC 状态定期检查，配置不匹配时自动重发。
- 兼容 TMC2225 `GCONF.en_spreadCycle` 读写反相现象。
- 优化看门狗喂狗逻辑，减少异常卡死风险。
- 停止位光感中断立即关闭 STEP 脉冲，提高停止响应速度。
- 断料逻辑改为断料后继续工作 10 秒，仅延迟通知。
- 超时错误支持重新上料后自动恢复。
- 修复 `steps` 为 0、电流越界等潜在参数问题。
